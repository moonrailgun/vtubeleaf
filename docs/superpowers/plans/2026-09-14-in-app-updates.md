# 应用内更新

目标：启动后安静检查新版本，用户主动下载、安装并重启。沿用关于窗口、设置存储和 GitHub Releases。

架构：主窗口持有 Tauri updater 资源；关于窗口通过现有事件机制发送操作并展示状态。下载与安装分开；安装前保存设置、保护未保存录制并停止摄像头和跟踪。只允许主窗口调用 updater。

技术：Tauri 2 官方 updater、React、现有 Node 测试与 Playwright、GitHub Actions。

约束：不读取或输出私钥；不自动安装；浏览器预览不检查；不提交、推送或发布。macOS 更新压缩包必须来自最终签名、公证并 stapled 的应用。

1. 添加更新控制器行为测试，确认并发去重、忽略版本、下载失败重试和安装前保存失败时不会安装。运行 `node --experimental-strip-types --test tests/updater.test.ts`，先观察失败，再实现控制器。
2. 接入主窗口生命周期、关于窗口和页脚入口；自动检查默认开启，启动延迟 5 秒、运行中每 24 小时检查。持久化自动检查与忽略版本设置。用现有 IPC mock 验证界面状态。
3. 配置公钥、更新端点及最小权限。发布时签名 Windows 安装器；macOS 最终应用生成 tar.gz 后签名。生成包含三个平台键的 latest.json，先验证产物齐全再发布。
4. 添加清单生成行为测试。运行 Node 测试、TypeScript、前端构建、Rust 测试和相关浏览器测试；检查工作流与差异。真实签名发布及跨版本安装由后续 release CI 和两个平台实测验证。
